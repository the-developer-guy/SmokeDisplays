# Smoke Display

Arduino library to drive salvaged displays.

**IMPORTANT!** This is not endorsement for smoking, vaping, or any similar stuff. This project only focuses on using the internals of these. Don't buy just to get one of these, you'll surely find someone with a bag of empty vapes. (that's how I ended up having hundreds of them)

## Supported devices

### Stag bar 6in1 180K

It has a 6-pin Charlieplexed 2.5 digit display, one thunder and one droplet icon. It has an extra 1-6 number display on the bottom!

### Vapsolo Quads 80000 4in1 

It has a 6-pin Charlieplexed, 2.5 digit display with bicolor droplet, bicolor battery and percent.
